🔴🔴 **Bug 1：撰写与续写生成完之后无法落笔（本轮最严重的发现）**
现象：续写生成 84 字符（84→168），**没有任何落笔 UI 出现**。
根因：落笔按钮当时只在选区气泡上，而气泡 `measure()` 在选区为空时返回 null →
撰写/续写根本没有选区 → 气泡不渲染 → 生成的文本静默躺在编辑器里
（按设计它不进历史、不触发保存），**用户看得见却保不住，刷新即失，
而且它看起来像已经写进笔记了**。这正是流式方案"静默写入"的代价，
若只做单测永远发现不了——`stream-writer` 的 11 条断言全绿。
修法：落笔从气泡搬到常驻状态条，`reviewModes(state)` 按动作给按钮并**恒不为空**；
气泡退回只负责选动作。补了 4 条断言，其中一条就是「任何动作都必须至少有一个落笔方式」。

🔴 **Bug 2：图片请求被 403 挡下**
`requestImage` 用裸 `fetch`，绕过 `lib/api.ts` 统一加 `X-Inkstone-Client` 的路径，
