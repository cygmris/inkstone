【slug 的边界】
空提示词 / 全标点 → 回落 `ai-image`；超长 → 截到 40 字符**且不以分隔符结尾**；
用 `\p{Letter}\p{Number}` 而非 `a-z0-9`，所以中文提示词不会被清成空串。

`image-request.test.ts:30 Chinese text is allowed only in zh-CN.ts`。
已改为 `橘猫` 这类转义。**这道门是有效的，不是摆设**——
上一个 spec 也被它抓过一次，说明这个错误我会重复犯，靠自觉记不住。

一致，从而能被既有 `classifyAiError` 正确分类成 429 / http 等——错误文案因此自动复用。
