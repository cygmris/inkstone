## Verification

【实测依据 —— 这条不是读文档来的，官方文档明确说没有这类参数】
先用 Global API Key 直接打 Cloudflare 原生 API 试了 6 种写法（qwen3 / gpt-oss-20b，同一 prompt，max_tokens=300）：

| 写法 | reasoning chunk | completion_tokens | neurons |
| qwen3 基线 | 111 | 117 | 3.63 |
| **chat_template_kwargs:{enable_thinking:false}** | **0** | **3** | **0.17** |
| enable_thinking:false（平铺） | 118 | 124 | 3.84（无效） |
| prompt 里加 /no_think | 1 | 7 | 0.30 |
| gpt-oss reasoning_effort:'low' | 7 | 19 | 1.88 |
| gpt-oss reasoning:{effort:'low'} | 52 | 64 | 3.11（无效） |

→ chat_template_kwargs 那条把 neurons 从 3.63 降到 0.17，**约 21 倍**。

再对 7 个模型逐个探测（同时带两个参数）：
qwen3 / gemma-4 / llama-4-scout / llama-3.3-70b → reasoning 归零，completion_tokens 一律 3
gpt-oss-20b → 22 token（从 61 降）；gpt-oss-120b → 20 token
🔴 **mistral-small-3.1-24b 报 400**：AiError「chat_template is not supported for Mistral tokenizers」

隔离验证：单独只发 reasoning_effort 时 mistral 正常 → **被拒的确定是 chat_template_kwargs**，不是 reasoning_effort。
另测出 mistral 本来就不输出思维链（基线 completion_tokens=3，reasoning=0），所以它压根不需要这个参数——与它拒绝该参数正好自洽。

qwen3 200 / 3 chunks / "\n\nhello world"；**mistral 200 / 2 chunks / "Hello world"（没被打挂）**；gemma-4 200 / 2 chunks。
