## Verification

线上实测（部署后从浏览器打真实路由）：
- 未带 X-Inkstone-Client 头 → 403 forbidden「Missing client identification header」（上游中间件生效）
- 付费模型 @cf/moonshotai/kimi-k2.6 → 400 bad_request「That model is not available on this server」
- 任意字符串 gpt-4 → 400
- 空 messages → 400「messages must be a non-empty array」
- 非法 role → 400「each message needs a role of system, user or assistant」
- 合法请求 → 200 + content-type: text/event-stream; charset=utf-8

npm run typecheck 与 npm run deploy:check 通过。

模型白名单是安全要求而不是形式：不校验的话这条路由就成了「登录用户可以拿它打任意 Workers AI 模型」的开放代理，消耗的是账号额度。

⚠️ 429 那条路径（额度耗尽）**未实证**——没撞到过。upstreamFailure 里那个正则是按标准语义写的，不是观测出来的，等真撞到再按实际返回校正。
