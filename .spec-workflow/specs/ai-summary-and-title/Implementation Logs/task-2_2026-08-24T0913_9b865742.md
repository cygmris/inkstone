## Verification

两条断言，均通过：

1. `deriveExcerpt(insertSummary(note, SUMMARY))` 对一篇含 frontmatter + 一级标题 + 二级标题的笔记：
   - `startsWith(SUMMARY)` → true
   - 不含 `>` → true
   - 不含 `[!` → true
2. 摘要前后的 excerpt 不同（证明这个动作确实改变了列表预览，而不是碰巧一致）

**与 design 里那条实测的对照**（这才是这个任务存在的理由）：
- `> [!NOTE]` 块 → excerpt 实测为 `"[!NOTE] 本周把发布流程从手工改成脚本... 背景 原来的发布..."` —— 标记漏出来了
- 普通 `>` 块 → excerpt 实测以摘要句开头、无标记

`toPlainText` 会剥离 `>` 但不剥离 `[!NOTE]`。所以「用不用 callout」不是风格问题，是**功能成不成立**的问题。design 里已把这条写成硬约束（需求 1.5）。
